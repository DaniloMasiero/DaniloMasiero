## Projects

**[Weekly demand forecasting for inventory planning](https://github.com/DaniloMasiero/demand-forecasting-inventory)**
Global LightGBM model for 526 products of a real online retailer (1M transactions), validated with a
rolling-origin backtest and a separate validation period.
- 4.7% lower WAPE than the best baseline, with the same bias
- 12-16% less safety stock for the same service level
- Found that L1 loss under-forecasts skewed demand by 20%, and fixed it with quantile loss
